## 🚀 Ready to Run

### Two-Minute Setup

```bash
# Unix/Mac
chmod +x quickstart.sh
./quickstart.sh

# Windows
quickstart.bat
```

Then start:
```bash
# Terminal 1
cd backend && uvicorn app.main:app --reload --port 8000

# Terminal 2
cd frontend && npm run dev
```

Access: **http://localhost:3000**
